Question 1

Library Management System

15 marks

Build a simple library system that manages books. The system should allow adding books, borrowing books, returning books, and displaying all books with their availability status.

Requirements
  • Create a class Book with attributes: title, author, available (boolean)
  • Create a class Library that stores a list of books
  • Method add_book(title, author)
  • Method borrow_book(title) marks book as unavailable
  • Method return_book(title) marks book as available
  • Method show_books() prints all books with their status
  • Demonstrate with at least 3 books and 2 transactions
Sample OutputBook added: The Hobbit Book added: 1984 Borrowed: The Hobbit Available books: 1984 - Available The Hobbit - Borrowed
Question 2

Student Grade Tracker

12 marks

Create a program that tracks student grades. The program should accept multiple students with their scores, calculate the class average, and identify the highest and lowest scoring students.

Requirements
  • Use a dictionary to store student names and their scores
  • Include at least 4 students
  • Calculate the class average
  • Find the highest scoring student
  • Find the lowest scoring student
  • Print all results in a clearly formatted way
Sample OutputStudents: Alice:85, Bob:92, Carol:78, Dave:88 Average: 85.75 Highest: Bob (92) Lowest: Carol (78)
Question 3

Bank Account System

15 marks

Build a bank account class that supports deposits, withdrawals, and balance checking. The system must handle insufficient funds gracefully with an appropriate message.

Requirements
  • Create class BankAccount with owner and balance attributes
  • Method deposit(amount) adds to balance
  • Method withdraw(amount) subtracts from balance, but checks for sufficient funds
  • Method get_balance() returns current balance
  • Demonstrate with example transactions including a failed withdrawal
Sample OutputAccount: John Deposited: 500 Balance: 500 Withdrew: 200 Balance: 300 Insufficient funds for 500
Question 4

Word Frequency Counter

12 marks

Write a program that counts how many times each word appears in a given text. The program should display the top 5 most frequent words.

Requirements
  • Accept a text string (hardcoded is acceptable)
  • Split the text into individual words
  • Count frequency of each word (case-insensitive)
  • Sort words by frequency in descending order
  • Display the top 5 words with their counts
Sample OutputTop 5 words: the: 4 quick: 2 brown: 2 fox: 2 jumps: 1
Question 5

Temperature Converter

10 marks

Create a temperature converter that converts between Celsius, Fahrenheit, and Kelvin. Use separate functions for each conversion.

Requirements
  • Function celsius_to_fahrenheit(c)
  • Function fahrenheit_to_celsius(f)
  • Function celsius_to_kelvin(c)
  • Function kelvin_to_celsius(k)
  • Demonstrate all conversions with example values
Sample Output0C = 32.0F 100C = 212.0F 32F = 0.0C 0C = 273.15K 273.15K = 0.0C

To-Do List Manager

Build a to-do list application that allows adding tasks, marking them as complete, and listing all tasks with their current status.

Question 7

Student Report Card

12 marks

Create a report card generator. Given a student's name and a dictionary of subjects with scores, calculate the average and assign a final grade.

Requirements
  • Accept a student name and subject scores
  • Calculate the average score
  • Assign grade: A (90+), B (80-89), C (70-79), D (60-69), F (below 60)

Question 8

Inventory Management System

12 marks

Build an inventory system for a small store. Track products with quantity and price. Support adding products, selling, restocking, and calculating total inventory value.

Requirements
  • Class Product with name, quantity, and price
  • Class Inventory holding a list of products
  • Method add_product(name, qty, price)
  • Method sell(name, qty) reduces quantity, errors if insufficient stock
  • Method restock(name, qty) increases quantity
  • Method total_value() returns the total value of all inventory
  • Method show_inventory() displays all products
Sample OutputAdded: Apples x10 @ R5 Added: Bread x5 @ R15 Sold: 3 Apples Restocked: 5 Bread Total value: R145 Apples: 7 (R5) Bread: 10 (R15)
